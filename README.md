# Qiwisteam-bot
Телеграм бот с прокси для покупки цифровых товаров 
-
Создан для продажи ненужных ключей и иных продуктов. 
Есть механика реферальных ссылок, казино, управление аккаунтами, покупка и выставление товаров. 
Сделана на json, т.к. особо не перегружается данными. 
-
Библиотеки
telebot
-
Подключением яввляется с помощью data.json
